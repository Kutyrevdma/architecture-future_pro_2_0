# Terraform модуль для создания виртуальных машин в нескольких окружениях

## Описание

В рамках данного задания реализован переиспользуемый Terraform‑модуль для создания виртуальной машины в Yandex Cloud. Модуль предназначен для использования в нескольких окружениях: **dev**, **stage** и **prod**.

Основная цель — построить модульную инфраструктуру, где один и тот же модуль Terraform используется с разными параметрами конфигурации для разных окружений.

Модуль выполняет следующие задачи:

* создание виртуальной машины
* создание и подключение дополнительного диска
* настройку сетевого интерфейса
* передачу SSH‑ключа для доступа
* вывод информации о созданных ресурсах

Все параметры передаются через переменные, внутри модуля **нет захардкоженных значений окружений**.

# Описание модуля

Модуль расположен в директории:

```
modules/vm
```

Он отвечает за создание следующих ресурсов:

* виртуальная машина (Compute Instance)
* подключаемый диск
* сетевой интерфейс

Модуль спроектирован так, чтобы его можно было использовать в разных окружениях с разными параметрами.

---

# Входные параметры модуля

| Переменная | Описание                       |
| ---------- | ------------------------------ |
| vm_name    | Имя виртуальной машины         |
| cores      | Количество CPU                 |
| memory     | Объём оперативной памяти       |
| disk_size  | Размер подключаемого диска     |
| subnet_id  | ID подсети                     |
| ssh_key    | Публичный SSH‑ключ для доступа |

---

# Выходные параметры (Outputs)

| Output        | Описание               |
| ------------- | ---------------------- |
| instance_id   | ID виртуальной машины  |
| instance_name | Имя виртуальной машины |
| external_ip   | Внешний IP адрес       |
| disk_id       | ID подключенного диска |

# Установка Terraform

Установить Terraform можно через snap:

```
sudo snap install terraform --classic
```

Проверка установки:

```
terraform -version
```

---

# Установка Yandex Cloud CLI

Установка CLI:

```
curl https://storage.yandexcloud.net/yandexcloud-yc/install.sh | bash
```

После установки необходимо перезапустить shell:

```
exec -l $SHELL
```

Проверка установки:

```
yc version
```

---

# Авторизация в Yandex Cloud

Инициализация CLI:

```
yc init
```

В процессе настройки необходимо:

1. Создать новый профиль
2. Получить OAuth токен
3. Выбрать облако
4. Выбрать или создать папку
5. Указать зону для Compute

Пример зоны:

```
ru-central1-a
```

---

## Настройка provider Yandex Cloud

В каждом окружении (`envs/dev`, `envs/stage`, `envs/prod`) необходимо указать конфигурацию провайдера Yandex Cloud.

Пример файла `provider.tf` или блока в `main.tf`:

```
provider "yandex" {
  token     = "<OAUTH_TOKEN>"
  cloud_id  = "<CLOUD_ID>"
  folder_id = "<FOLDER_ID>"
  zone      = "ru-central1-a"
}
```

### Как получить значения

**OAuth токен**

Получить токен можно при выполнении команды:

```
yc init
```

или вручную по ссылке:

```
https://oauth.yandex.ru/authorize
```

После авторизации будет выдан OAuth token.

---

**Получить cloud_id**

```
yc resource-manager cloud list
```

Пример вывода:

```
+----------------------+--------------------+
|         ID           |        NAME        |
+----------------------+--------------------+
| b1grfji99tp5f3qe9u70 | my-cloud           |
+----------------------+--------------------+
```

Используем значение `ID`.

---

**Получить folder_id**

```
yc resource-manager folder list
```

Пример:

```
+----------------------+---------------------+
|         ID           |        NAME         |
+----------------------+---------------------+
| b1gplj9ihkdugnifko94 | terraform-folder    |
+----------------------+---------------------+
```

Используем значение `ID`.

---

**Зона размещения ресурсов**

В задании используется зона:

```
ru-central1-a
```

---


После заполнения конфигурации необходимо выполнить инициализацию Terraform.

```
terraform init
```

Затем можно запускать создание инфраструктуры.

```
terraform apply -var-file="dev.tfvars"
```


# Конфигурация окружений

Каждое окружение использует собственный файл переменных `.tfvars`.

## dev.tfvars

```
vm_name   = "vm-dev"
cores     = 2
memory    = 2

disk_size = 10
subnet_id = "<subnet_id>"

ssh_key   = "ubuntu:${file("~/.ssh/id_rsa.pub")}"
```

## stage.tfvars

```
vm_name   = "vm-stage"
cores     = 2
memory    = 4

disk_size = 15
subnet_id = "<subnet_id>"

ssh_key   = "ubuntu:${file("~/.ssh/id_rsa.pub")}"
```

## prod.tfvars

```
vm_name   = "vm-prod"
cores     = 4
memory    = 8

disk_size = 30
subnet_id = "<subnet_id>"

ssh_key   = "ubuntu:${file("~/.ssh/id_rsa.pub")}"
```

# Инициализация Terraform

Перейти в директорию нужного окружения:

```
cd envs/dev
```

Инициализировать Terraform:

```
terraform init
```

---

# Развёртывание инфраструктуры

Запуск Terraform с файлом переменных:

```
terraform apply -var-file="dev.tfvars"
```

Подтвердить выполнение:

```
yes
```

После выполнения Terraform создаст:

* виртуальную машину
* подключаемый диск

---

# Проверка созданных ресурсов

Список виртуальных машин:

```
yc compute instance list
```

Пример вывода:

```
ID                     NAME    EXTERNAL_IP     STATUS
xxxxxxxxxxxxxxxxxxxx   vm-dev  84.xxx.xxx.xxx  RUNNING
```

---

# Подключение к виртуальной машине

```
ssh ubuntu@<external_ip>
```

---

# Удаление инфраструктуры

Для удаления ресурсов:

```
terraform destroy -var-file="dev.tfvars"
```
