# Стратегический роадмап внедрения Data Mesh

Внедрение новой архитектуры выполняется поэтапно в течение трёх лет.

---

# Этап 1 — Пилот (0–6 месяцев)

Цель: проверить концепцию Data Mesh и построить базовую платформу данных.

| Задача | Роли | Результат |
|------|------|------|
| Формирование платформенной команды | Platform Lead, DevOps, Data Engineer | Развёрнута инфраструктура данных |
| Развёртывание Kafka и Data Lakehouse | DevOps, Data Engineer | Платформа данных готова |
| Выбор пилотного домена | Data Product Owner | Определён первый дата-продукт |
| Реализация первого дата-продукта | Data Engineer | Данные публикуются как события |
| MVP портала аналитики | Backend / Frontend разработчики | Пользователи могут строить отчёты |

Бизнес-результат:

ускорение получения отчётов минимум в **2 раза**

---

# Этап 2 — Масштабирование (6–18 месяцев)

Цель: распространить Data Mesh на ключевые домены.

| Задача | Роли | Результат |
|------|------|------|
| Подключение новых доменов | Domain Data Product Owner | Публикация новых дата-продуктов |
| Федеративное управление данными | Data Governance Council | Введены стандарты данных |
| Реализация потоковых витрин | Data Engineers | Near-real-time аналитика |
| Интеграция легаси через ACL | Integration Engineers | Легаси публикует события |
| Развитие портала аналитики | Frontend / Backend | Расширенный конструктор отчётов |

Бизнес-результат:

сокращение времени получения данных **в 3 раза**

---

# Этап 3 — Полноценная платформа (18–36 месяцев)

Цель: переход к полноценной событийной платформе.

| Задача | Роли | Результат |
|------|------|------|
| Вывод из эксплуатации legacy DWH | Архитекторы | Данные доступны через дата-продукты |
| Интеграция партнёров | API Developers | Подключение внешних систем |
| Data Observability | Platform Team | Контроль качества данных |
| Развитие ML платформы | ML Engineers | Использование данных для моделей |
| Оптимизация облачных затрат | DevOps / FinOps | Снижение TCO |

Бизнес-результат:

- запуск новых продуктов
- выход на новые регионы
- near-real-time аналитика
