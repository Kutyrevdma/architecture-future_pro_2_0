# Расширенный технический радар (Tech Radar)

Технический радар отражает используемые технологии, инструменты и архитектурные паттерны целевой платформы данных компании «Будущее 2.0».

Статусы технологий:

- **Adopt** — активно используется в архитектуре
- **Trial** — используется в пилотных проектах
- **Assess** — технология оценивается
- **Hold** — не рекомендуется к использованию

---

# Архитектурные паттерны (Techniques)

| Паттерн | Статус | Описание |
|-------|------|-----------|
| Data Mesh | Adopt | Децентрализованная модель управления данными, где каждый домен владеет своими дата-продуктами. |
| Event-Driven Architecture | Adopt | Основная модель взаимодействия доменов через события. |
| Self-Service BI | Adopt | Пользователи самостоятельно строят отчёты через портал аналитики. |
| Data Product | Adopt | Данные публикуются как продукт с владельцем и SLA. |
| Federated Data Governance | Trial | Федеративное управление данными между доменами. |
| Data Contracts | Trial | Контракты между источниками и потребителями данных. |
| Data Observability | Assess | Мониторинг качества данных и lineage. |

# Платформенные технологии (Platforms)

| Платформа | Статус | Описание |
|---------|------|-----------|
| Cloud Infrastructure (AWS / Yandex Cloud) | Adopt | Основная инфраструктура для размещения сервисов и платформенных компонентов. |
| Apache Kafka | Adopt | Брокер событий для обмена сообщениями между доменами. |
| Data Lakehouse (S3 + Iceberg) | Adopt | Хранилище аналитических данных с поддержкой ACID-транзакций. |
| Trino | Adopt | SQL-движок для распределённых аналитических запросов. |
| DataHub | Adopt | Каталог данных и метаданных. |
| Apache Airflow | Adopt | Оркестрация пайплайнов обработки данных. |
| Kubernetes | Adopt | Оркестрация контейнеров и микросервисов. |
| Superset / Power BI | Trial | Инструменты визуализации данных. |
